# Digital Desk 安装与使用指南

Digital Desk 是一个面向 Obsidian 用户的首页工作台。你可以在一个页面里新建笔记、建立项目、记录灵感、找回最近文件、查看进行中的工作和待办。微信读书阅读台属于可选功能，日常使用不依赖其他社区插件。

![Digital Desk 工作台预览](digital-desk-preview.jpg)

## 安装前

- Obsidian 版本需要达到 `1.13.0` 或更高版本。
- 插件会读取当前仓库中的文件和目录，用来生成目录选择器、最近文件、项目卡片和待办列表。
- 建立工作台时，插件会创建你指定但尚不存在的目录和起始文件。已有文件和目录会保留。

## 从 Obsidian 安装

1. 打开 Obsidian 设置。
2. 进入第三方插件页面。
3. 点击浏览，在搜索框中输入 `Digital Desk`。
4. 打开插件详情，依次点击安装和启用。
5. 启用后会出现首次设置窗口。

也可以打开 [Digital Desk 社区页面](https://community.obsidian.md/plugins/digital-desk)，点击安装按钮唤起 Obsidian。

## 第一次建立工作台

首次设置窗口会让你确认六个位置。

- 收件箱用于临时笔记和待整理内容。
- 项目目录用于集中放置项目文件夹。
- 笔记目录用于长期笔记和知识资料。
- 灵感目录用于保存首页快速记录的想法。
- 待办文件用于展示尚未完成的 Markdown 任务。
- 阅读划线文件用于归档可选的微信读书划线。

默认位置可以直接使用，也可以换成你已有的目录。填写完成后点击建立工作台。插件会补齐缺失的目录、待办文件和划线文件。

如果当时选择了稍后设置，可以进入设置中的 Digital Desk 页面重新配置，再点击建立目录。

## 打开工作台

安装完成后，有三种打开方式。

- 点击左侧边栏的首页图标。
- 打开命令面板，运行 `Digital Desk: Open dashboard`。
- 在插件设置中点击打开工作台。

默认会在 Obsidian 启动后打开工作台。这个行为可以在设置中关闭。

## 新建笔记

1. 点击首页的「新建笔记」。
2. 搜索并选择笔记所在目录。
3. 输入标题并点击创建。

目录选择器会结合使用次数和最近使用时间排序。经常使用的目录会逐渐排到前面。新笔记创建后会立即打开，并写入创建时间和同名一级标题。

## 新建项目

1. 点击首页的「新建项目」。
2. 选择项目的上级目录。
3. 输入项目名称并点击创建项目。

插件会建立一个同名文件夹，并在其中创建 `README.md`。项目文件预先带有目标、下一步和未完成任务，方便马上开始记录。

需要建立多级项目时，先选择现有项目文件夹作为上级目录，再输入子项目名称。

## 记录灵感

点击「记录灵感」，输入一句话标题。插件会在设定的灵感目录中新建一篇笔记，文件名带有日期和时间，随后自动打开。

## 最近文件

首页默认显示最近三个 Markdown 文件，可以在设置中调整为三到八个。

- 单击卡片打开文件。
- 右击卡片可以打开、重命名或移到废纸篓。
- 其他插件添加到 Obsidian 文件菜单中的操作也会出现在这里。

移动到废纸篓前会再次确认。文件最终进入系统废纸篓还是仓库废纸篓，取决于你的 Obsidian 设置。

## 正在进行

没有额外设置时，工作台会读取项目目录的一级子文件夹，并按照最近修改时间展示最多六个项目。

想固定显示特定项目，可以进入 Digital Desk 设置，在「固定项目」中每行填写一个目录。显示名称可以省略，也可以按下面的格式填写。

```text
内容系列 | 01-projects/content-series
网站重构 | 01-projects/site
```

设置固定项目后，首页会按照这里填写的顺序展示。

## 今日待办

工作台从设定的待办文件中读取前六条未完成任务。支持常见的 Markdown 任务格式。

```markdown
- [ ] 整理采访提纲
- [ ] 完成文章初稿
```

点击首页中的任务会打开完整待办文件。任务的勾选和编辑仍在原始 Markdown 文件中完成。

## 快速入口

进入 Digital Desk 设置，在「快速入口」中每行填写一个文件或目录路径。设置完成后，首页会出现相应入口。

```text
03-notes/knowledge-base.md
assets
```

文件会直接打开。目录会打开其中最近修改的 Markdown 文件。

## 首页金句

没有配置微信读书时，首页会显示插件内置的短句，每小时自动更新。单击短句可以立即换一句。

配置微信读书后，这个位置会轮播已同步的个人划线，并显示书名和作者。单击来源会打开本地划线归档中的对应位置。

## 微信读书阅读台

阅读台可以展示书架、阅读统计、继续阅读和最近划线。这个功能需要个人微信读书 API 密钥。

1. 前往 [WeRead Skills](https://weread.qq.com/r/weread-skills) 获取个人密钥。
2. 打开 Digital Desk 设置。
3. 在「微信读书 API 密钥」中输入以 `wrk-` 开头的密钥并保存。
4. 回到工作台，点击阅读台右上角的同步图标。

密钥保存在 Obsidian 的安全密钥存储中，不会写进笔记或插件日志。启用阅读台后，插件会连接腾讯微信读书接口，读取书架、阅读统计和个人划线。

新划线产生后，可以点击同步图标立即更新。工作台也会在本地缓存过期后尝试刷新。同步成功的划线会写入设定的 Markdown 文件，并带有稳定的块链接。你可以在同步区域之外继续写自己的读书笔记。

点击最近划线会跳转到本地归档。点击书架或继续阅读中的书籍会尝试打开微信读书提供的阅读链接。

如果不需要阅读台，可以在设置中关闭显示阅读台，也可以清除已经保存的 API 密钥。

## 调整首页内容

打开 Obsidian 设置，进入 Digital Desk，可以调整以下内容。

- 工作台名称和一句话说明
- 收件箱、项目、笔记和灵感目录
- 待办文件和微信读书划线文件
- 固定项目和快速入口
- 最近文件数量
- 启动时打开工作台
- 今日待办和阅读台的显示状态
- 微信读书书架展示数量

设置目录和文件路径时，请填写相对于当前 Obsidian 仓库根目录的路径。

## 隐私与文件访问

Digital Desk 在当前 Obsidian 仓库内运行。目录选择器、最近文件和项目发现需要读取仓库中的文件路径与修改时间。新建笔记、建立项目、记录灵感、重命名和移到废纸篓会通过 Obsidian 提供的文件接口执行。

阅读台关闭或未配置时，插件不会请求微信读书数据。插件没有开发者中转服务器，也不包含广告、分析统计或遥测。

提交问题时，请勿在截图、日志或 Issue 中公开自己的仓库内容和 API 密钥。

## 常见问题

### 启用后没有看到首页

点击左侧边栏的首页图标，或者在命令面板运行 `Digital Desk: Open dashboard`。随后检查设置中的「启动时打开工作台」是否开启。

### 首页提示找不到目录或文件

打开 Digital Desk 设置，检查相应路径是否与当前仓库一致。修改完成后点击建立目录，让插件补齐缺失位置。

### 常用目录没有排在前面

目录排序会随着新建笔记和项目的使用记录逐步调整。也可以在目录选择器中直接输入目录名称进行搜索。

### 项目卡片显示了不需要的目录

在「固定项目」中填写想展示的项目路径。填写后，自动发现的项目会由固定列表取代。

### 阅读台无法同步

先检查 API 密钥格式和网络连接，再点击同步图标重试。密钥失效时，可以在设置中保存新的密钥。提交问题时不要粘贴完整密钥。

### 划线文件提示同步标记缺失

插件只更新下面两个标记之间的区域。

```html
<!-- digital-desk-weread:start -->
<!-- digital-desk-weread:end -->
```

标记被删除后，插件会保留现有内容并停止写入。可以重新加入这两个标记，或者在设置中选择一个新的划线文件。
